# Session 02

## Mission 1

1회차 PR을 다른 스터디원과 Review합니다.

- Files changed 확인
- Review 작성
- Approve
- 본인 PR Merge

## Mission 2

배정받은 Convention에 따라 새로운 작업을 진행합니다.

1. Convention 확인
2. Issue 생성
3. 최신 main 가져오기
4. Convention에 맞는 Branch 생성
5. participants/{github-id}.md 수정
6. Convention에 맞게 Commit
7. Push
8. Pull Request 생성
9. Issue 연결
10. 다른 스터디원의 PR Review & Approve
11. 본인 PR Merge

자세한 방법은 2회차 학습 자료를 참고해주세요.
